# Secure Remote SOC Lab

## Purpose
A collaborative SOC environment for current and future interns.

## Platform
Wazuh SIEM, Windows Sysmon endpoints, and an authorized shared Kali testing environment.

## Workstreams
- Security monitoring and alert triage
- Detection use-case development
- Incident-response playbooks
- Controlled alert generation
- Testing and peer review
- Approved deployment
- Evidence collection and reporting

## Change Workflow
Develop -> Test -> Review -> Approve -> Deploy -> Validate
