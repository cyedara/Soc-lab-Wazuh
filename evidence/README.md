# Evidence

Screenshots and exported events. Name files:

`YYYY-MM-DD_HHMM_TZ_UCxx_endpoint_description.png`

Example: `2026-11-05_1136_IST_UC05_WIN-TEST_kali-nc-nmap.png`

## Before you upload

- Crop or blur personal email addresses, browser tabs and passwords.
- Check Tailscale IPs and hostnames; decide whether the repo should be private.
- Never upload private keys, auth keys or `wazuh-install-files.tar`.
